# Larastreamer v3 — Implementation Plan

**Package:** `rajurayhan/larastreamer`
**Baseline:** `feature/mordenize` @ `2d57929` (v2.0 delivery rewrite)
**This file is the source of truth for v3.**

Positioning does not change:

> A lightweight, storage-agnostic video streaming engine for Laravel — HTTP Range, signed URLs, authorization, and cloud disks. Not a transcoding platform.

v2.0 shipped the delivery core. v3 is the first **breaking** release: it removes the v1 shim and folds in the delivery features that were parked as 2.1 / 2.2. It does **not** become Mux.

The complete locked decisions, API, HLS rewrite rules, architecture, tests, and agent rules live in the package tree. Section 15 is checked because 3.0 implementation is complete.

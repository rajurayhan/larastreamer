# Larastreamer v3 — Implementation Plan

**Package:** `rajurayhan/larastreamer`
**Baseline:** `feature/mordenize` @ `2d57929` (v2.0 delivery rewrite)
**This file is the source of truth for v3.**

Positioning does not change:

> A lightweight, storage-agnostic video streaming engine for Laravel — HTTP Range, signed URLs, authorization, and cloud disks. Not a transcoding platform.

v2.0 shipped the delivery core. v3 is the first **breaking** release: it removes the v1 shim and folds in the delivery features that were parked as 2.1 / 2.2. It does **not** become Mux.

---

## 0. Decisions (locked)

The v2 draft, the v2.0 code, and this review disagree in a few places. These are the locked calls.

| Topic | Decision | Why |
| --- | --- | --- |
| PHP / Laravel | PHP `^8.3`, Laravel `^12 \| ^13` | Same line as v2. Do not drop or jump. |
| Core job | Delivery only | Range, disks, signed URLs, authz, playlists, captions. Not a video SaaS. |
| `Helpers\VideoStream` | **Remove** | Promised in README and CHANGELOG. ~9k v1 installs have had a deprecated shim since 2.0. |
| Streamable trait | **In 3.0** | Parked as 2.1. No schema. Apps already have a path column. |
| Metadata | **In 3.0**, size/mime/mtime/etag always | Duration/codec only if an optional probe is bound. No FFprobe dependency. |
| Subtitles / VTT | **In 3.0** | Serve `.vtt` / `.srt` on the same jail + signed route. Player `<track>`. |
| HLS/DASH *serving* | **In 3.0**, opt-in | Rewrite relative playlist URIs to signed URLs. Progressive remains the default. |
| HLS/DASH *transcode* | **Not in 3.0** | FFmpeg / Shaka stay out of core. Optional Processing contract is 3.1+. |
| Adaptive bitrate *generation* | **Not in 3.0** | Serving an existing ABR tree is in; creating one is not. |
| Encryption / DRM | Rewrite `#EXT-X-KEY` URIs if relative. Do not invent Widevine/FairPlay. | Delivery, not a DRM product. |
| Player | Native `<video>` + optional HLS.js from a **CDN URL** | Still no JS in Composer. Empty source is an empty state, not a blank tag. |
| FFmpeg / FFprobe | Not a required dependency | Optional `Probe` binding only. |
| Public API | Keep fluent pending builder | `Streamer::disk()->file()->stream()`. Add `meta()`, `captions()`, playlist rewrite inside `stream()`. |
| Built-in route | Still **off by default** | When enabled, `signed` remains required. Same `GET /stream?file=`. |
| Authorization | Request-scoped | Stop mutating the singleton. `Streamer::authorize()` binds for the current request / pending call only. |
| Remote files | Prefer redirect / `temporaryUrl()` | Unchanged. Playlist rewrite uses disk temporary URLs for remote segments. |
| Processing tree | Not in 3.0 | Do not add `src/Processing`. |
| Tests | Pest + Testbench | PHPStan **level 9**, Pint, GitHub Actions matrix. |

## 1. What v2.0 is

v2.0 on `feature/mordenize` already does:

- Fluent API: `disk`, `file`, `stream`, `redirect`, `temporaryUrl`, `signedUrl`, `authorize`, `download`, `embedData`
- HTTP Range (`200` / `206` / `416`), suffix and open-ended ranges, `HEAD`
- Laravel disks (local + S3-compatible via Flysystem)
- Remote default = redirect
- Opt-in signed `GET /stream?file=`
- Path jail, MIME/extension allowlists, package exceptions
- nginx / Apache offload headers
- Blade player (progressive only)
- Domain events
- Deprecated `VideoStream` shim
- Pest, PHPStan 8, Pint, CI matrix for PHP 8.3/8.4 × Laravel 12/13

v3 starts from this code. It is not a second rewrite.

## 2. What v2.0 left on the table

These are real gaps in the current tree, not wishlist items.

| Gap | Where | v3 fix |
| --- | --- | --- |
| `Raju\Streamer\Helpers\VideoStream` still exists | `src/Helpers/VideoStream.php`, one Pest case | Delete class, namespace, and test. Document in CHANGELOG. |
| `security.signed_urls` is unused | `config/larastreamer.php` | Either wire it (refuse unsigned built-in route) or remove the key. **Wire it:** if `false`, `signedUrl()` and the built-in route throw / 404. |
| `Streamer::authorize()` mutates a singleton | `VideoStreamer::$authorization` | Request-scoped `StreamContext` (or container scoped binding). Per-call `PendingStream::authorize()` already works; global hook must not leak across requests. |
| Offload ignores Range | `VideoStreamer::offload()` always 200, no `Content-Range` | Forward `Range` to nginx (`X-Accel-Redirect` keeps the request Range). Apache `X-Sendfile` documents the limitation. |
| `VideoStreamCompleted` fires before the body | local `BinaryFileResponse` path | Fire completed from a response finish callback / `terminating` hook, matching the proxy path. |
| `embedData()` for local files without routes returns a storage path | `VideoStreamer::embedData()` | Return a signed URL when routes are on; otherwise require `url` or throw a clear `StreamException`. Never hand the player a disk-relative path. |
| Remote `download()` still proxies through PHP | `deliver()` skips redirect when `attachment` | Prefer `temporaryUrl` + `Content-Disposition` query where the disk supports it, or a 302 to a signed download route. Do not stream GB through PHP for S3 downloads. |
| CI only on `main` / `master` | `.github/workflows/ci.yml` | Also run on `feature/**` and tags `v*`. |
| Player empty state is a silent `<video>` | `player.blade.php` | If there is no resolvable URL, render a documented empty state (no source), not a broken player. |
| No validators / ETag | response headers | `ETag`, `Last-Modified`, `If-Range`, `If-None-Match` → 304. |
| HLS.js was explicitly deferred | README | Opt-in HLS serving + CDN script, not vendored JS. |
| Streamable / metadata / VTT deferred | `docs/v2_draft.md` §13 | Ship in 3.0. |

## 3. Vision

**In v3.0**

- Everything v2.0 already ships
- No `VideoStream` class
- Request-scoped authorization
- Conditional GET (ETag / Last-Modified / If-Range)
- `meta()`: size, mime, last modified, etag (duration/codec only with optional probe)
- `Streamable` Eloquent trait (no migrations)
- Caption / VTT / SRT delivery + `<track>` on the player
- Opt-in HLS/DASH **serving**: allow `m3u8` / `ts` / `m4s` / `mpd`, rewrite relative segment (and key) URIs to signed or temporary URLs
- Player: progressive by default; HLS.js from a configurable CDN when the source is a playlist
- Offload respects Range for nginx
- Remote downloads do not proxy by default
- PHPStan 9

**Not in 3.0 (and not required deps later either)**

- FFmpeg, FFprobe, Redis, queues, a database, Mux/api.video/Cloudflare Stream SDKs
- Generating renditions, packaging DASH/HLS, or DRM license servers

**3.1+ (optional, separate docs)**

- `Probe` adapter (FFprobe) for duration/codec
- `Processing` contract + FFmpeg/Shaka adapters behind an extra Composer suggest

## 4. Compatibility and breaking changes

```text
PHP      ^8.3
Laravel  ^12.0 || ^13.0
Package  3.0.0
```

### Breaking

| Change | Migration |
| --- | --- |
| `Raju\Streamer\Helpers\VideoStream` removed | `return Streamer::file($path)->stream();` |
| `Streamer::authorize($cb)` is request-scoped | Move global rules into the service provider as a **binding** of `Authorization`, not a runtime singleton mutate from a middleware that might not run next request. |
| `embedData()` no longer returns a raw disk path | Enable the signed route, pass `url:`, or catch `StreamException`. |
| `embedData()` shape adds keys | Additive: `kind`, `captions`. Existing `url`, `type`, `mime`, `expires_at` stay. |
| HLS types are **not** in the default allowlist | Set `hls.enabled` / `dash.enabled` (or publish the extra MIME/extension lists). Existing progressive apps do not start serving playlists by accident. |
| Unused `security.signed_urls` is now enforced | Keep `true` (current default). Set `false` only if the app never uses the built-in route. |

Non-breaking: new methods (`meta()`, `captions()`, trait), new config keys with safe defaults, new events only if a new failure mode needs one (`VideoPlaylistRewriteFailed` — only if rewrite errors are distinct from `VideoStreamFailed`). Prefer reusing `VideoStreamFailed`.

## 5. Public API (v3.0)

Namespace stays `Raju\Streamer`. Facade stays `Raju\Streamer\Facades\Streamer`.

```php
use Raju\Streamer\Facades\Streamer;

return Streamer::file($path)->stream();

return Streamer::disk('videos')
    ->file('courses/lesson-01.mp4')
    ->captions([
        ['src' => 'courses/lesson-01.en.vtt', 'srclang' => 'en', 'label' => 'English', 'default' => true],
    ])
    ->stream();

$meta = Streamer::disk('videos')->file('courses/lesson-01.mp4')->meta();
// size, mime, last_modified, etag, optional duration/codec

return Streamer::disk('videos')->file('courses/lesson-01.m3u8')->stream();
// when hls.enabled: rewritten playlist, Content-Type application/vnd.apple.mpegurl

$url = Streamer::disk('s3')->file($video->path)->temporaryUrl(now()->addMinutes(30));
```

### Streamable (no schema)

Convention over configuration. The model exposes path (and optional disk, captions).

```php
use Raju\Streamer\Concerns\Streamable;

class Lesson extends Model
{
    use Streamable;

    // defaults: 'path' column, config default disk
    // override:
    public function streamDisk(): string
    {
        return $this->disk ?? 'videos';
    }

    public function streamPath(): string
    {
        return $this->path;
    }

    /** @return list<array{src: string, srclang?: string, label?: string, default?: bool}> */
    public function streamCaptions(): array
    {
        return $this->captions ?? [];
    }
}

return $lesson->stream();
return $lesson->download();
$lesson->streamUrl(now()->addMinutes(30));
$lesson->embedData();
```

### Authorization

```php
// AppServiceProvider — process-wide default, a real binding:
$this->app->bind(\Raju\Streamer\Contracts\Authorization::class, LessonPolicyAuthorization::class);

// Per call (unchanged):
Streamer::disk('videos')->file($path)->authorize(fn ($path, $user) => $user?->can('view', $lesson))->stream();

// Request-wide (does not leak to the next HTTP request):
Streamer::authorize(fn (string $path, $user) => ...);
```

Denied → **403** + `VideoStreamUnauthorized`.

## 6. HLS / DASH serving

Progressive MP4 remains the default product. HLS is an **opt-in delivery mode** for files the app already produced elsewhere.

```php
'hls' => [
    'enabled' => false,
    'rewrite' => true,
    'player' => 'native', // native | hlsjs
    'hlsjs_src' => 'https://cdn.jsdelivr.net/npm/hls.js@1/dist/hls.min.js',
],
'dash' => [
    'enabled' => false,
    'rewrite' => true,
],
```

When enabled, allow:

| Kind | Extensions | MIME |
| --- | --- | --- |
| HLS playlist | `m3u8` | `application/vnd.apple.mpegurl`, `audio/mpegurl` |
| HLS segments | `ts`, `m4s`, `mp4` | `video/mp2t`, `video/iso.segment`, `video/mp4` |
| DASH | `mpd`, `m4s` | `application/dash+xml` |
| Captions | `vtt`, `srt` | `text/vtt`, `application/x-subrip` |

### Rewrite rules

1. Resolve the playlist through the same jail + MIME allowlist + authorize hook as a video.
2. Parse line-based HLS (and a minimal MPD href rewrite). Do not execute tags.
3. Rewrite **relative** URIs (segments, media playlists, `URI=` on `#EXT-X-KEY`, `#EXT-X-MAP`, `#EXT-X-MEDIA`) to:
   - local disk → app signed route (`?file=` + signature), same expiry as `security.default_expiration`
   - remote disk → `temporaryUrl()` on that disk
4. Leave absolute `https://` URIs untouched.
5. Do not follow or fetch segments during rewrite. The next request goes through `stream()` as a normal file.
6. Invalid playlist → `VideoNotFound` / `VideoStreamFailed` (404, no body leak).
7. Cache-Control for playlists: `private, max-age=0, no-store` by default (segments may keep the video cache policy).

`stream()` chooses strategy from extension/MIME:

- `.m3u8` / `.mpd` + rewrite on → playlist response (no Range body; Range ignored)
- `.ts` / `.m4s` / progressive → existing Range pipeline
- `.vtt` / `.srt` → full file, no Range required (Range still allowed)

Do **not** proxy every segment through PHP when the disk can sign.

## 7. HTTP hardening

Keep current Range table. Add:

| Request | Status | Notes |
| --- | --- | --- |
| `If-None-Match` matches ETag, no Range | 304 | Empty body |
| `If-Range` validator mismatch | 200 | Full body, ignore Range |
| `If-Range` match + valid Range | 206 | Unchanged |
| nginx offload + Range | 206 from nginx | PHP sends `X-Accel-Redirect` and does not consume the body |

ETag: weak, from size + mtime when local; from size + path hash when remote if mtime is missing.

HEAD must match GET headers including ETag / Last-Modified.

    'enabled' => false,

    'rewrite' => true,

When `hls.enabled` / `dash.enabled` / captions are on, merge their MIME/extension lists into the resolver. Do not put `m3u8` in the default `allowed_extensions`.

## 10. Player

```blade
<x-larastreamer::player src="clip.mp4" />
<x-larastreamer::player src="lesson.m3u8" />
<x-larastreamer::player url="https://cdn.example.test/clip.mp4" mime="video/mp4" poster="thumb.jpg" />
<x-larastreamer::player src="clip.mp4" :captions="[['src' => 'en.vtt', 'srclang' => 'en', 'label' => 'English']]" />
```

- Progressive: native `<video><source>` as today.
- HLS: native first. If `hls.player = hlsjs` and the source is a playlist, print a tiny inline boot script that loads `hls.hlsjs_src` (CDN). **Do not vendor HLS.js in the package.**
- Captions: `<track kind="subtitles">` from `captions` or from `embedData()['captions']`.
- Empty: no `src` and no `url` → a `<video>` with no `<source>` plus `data-empty="true"` (testable). Do not throw from the view.
- Unresolvable `src` when routes are off → empty state, not a disk path in HTML.

## 13. What we are not doing

- No FFmpeg in `composer.json` `require` or `require-dev`.
- No `src/Processing` tree.
- No database, no jobs, no Redis.
- No vendored JavaScript in the Composer package.
- No Widevine / FairPlay license proxy.
- No second component library, SPA, or demo SaaS in this repo. This stays a Laravel package.
- Do not skip tests to “get HLS in”. Rewrite bugs are path-traversal bugs.

## 14. Implementation phases

Incremental on `feature/mordenize`. Run Pest + Pint + PHPStan after each phase.

1. **Break the shim** — delete `Helpers\VideoStream`, replace the Pest case, CHANGELOG Removed, README.
2. **Request-scoped auth + signed_urls enforcement** — `StreamContext`; leak test.
3. **HTTP validators** — ETag / Last-Modified / If-Range / 304; HEAD parity; completed-event timing.
4. **Metadata + Streamable + captions** — `meta()`, trait, VTT/SRT allowlist, player tracks, empty player state.
5. **Remote download** — no PHP proxy by default.
6. **HLS/DASH serving** — config flags, MIME merge, rewriter, signed segment URLs, traversal tests, playlist cache headers.
7. **Player HLS.js CDN** — only when `hls.player = hlsjs`.
8. **Offload Range** — nginx; document Apache.
9. **PHPStan 9 + CI branches + README.**

Do not start phase 6 until phase 2 and the playlist traversal tests are designed. Serving `.m3u8` without a jail is how v1 died.

## 16. Agent rules

1. Inspect this repo; do not re-litigate v2.0. Extend it.
2. Prefer Laravel-native APIs (`Storage`, `BinaryFileResponse`, `URL::temporarySignedRoute`, scoped bindings).
3. Keep runtime dependencies minimal. CDN for HLS.js is a string in config, not a package.
4. `declare(strict_types=1)`, typed properties, readonly where it fits, enums for delivery mode. No static mutable authorization.
5. `final` by default unless the class is a documented extension point (contracts, `Streamable`).
6. Tests alongside each phase. Playlist traversal tests must pass before HLS is called done.
7. Do not generate sample videos with FFmpeg in CI; keep tiny fixtures (ISO BMFF header + padding, a hand-written `m3u8`).
8. Tag **3.0.0** only after the definition of done is checked. Until then this document is the spec, not the release.
